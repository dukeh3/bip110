Then you clearly don't understand what money is. The ability to send messages along with the payment has been an integral part of money since kings and emperors learned the power of putting their face on a coin. In fact it's so powerful that there are some kings we only know exist because of the coins they minted.

It was true then, and it is still true today, name me the coin or note that does not bear a king or a national symbol designed by its issuer. Every bank that issues a VISA card puts its logo on the card, and you are forced to have VISA's logo there. Some banks are even issuing user designed cards. Many clearing systems allow the user to add a message to the transaction, a reference number or a short message tagging an invoice.

Bitcoin is no exception here, when Satoshi minted the genesis block he added a note, clearly tagging important events at the time.

So if it's a blockchain that is free from user messages "spam" you seek then perhaps you should consider a different one from bitcoin, because here we have had user inserted messages since inception.
